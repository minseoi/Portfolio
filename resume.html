자기소개

언리얼엔진과 C++로 게임 클라이언트를 개발해온 5년차 프로그래머입니다. 캐릭터나 전투, 스킬/버프, UI처럼 게임 안에서 동작하는 기능을 주로 맡아왔고, 3개의 프로젝트를 개발 초기부터 출시와 운영까지 경험했습니다.

개발하면서 문제가 생기면 눈에 보이는 현상만 고치기보다 원인을 찾으려고 합니다. 로그와 콜스택을 따라 코드를 분석하고, 필요하면 엔진 소스까지 확인합니다. 클라이언트뿐만 아니라 서버의 처리 과정까지 살펴보며 문제를 해결해 왔습니다.

기능을 만들 때는 당장의 동작뿐만 아니라 이후의 수정과 확장도 고려합니다. 스킬과 버프, 레벨 로딩, 튜토리얼 등 여러 기능을 개발하면서 데이터와 코드 구조를 개선해 왔으며, 기존 코드에서도 문제가 보이면 원인을 파악하고 리팩토링을 진행하는 작업을 해왔습니다.

C++기반 소켓 서버와 Dedicated Server 환경을 경험했으며, C++ 서버의 콘텐츠 개발에도 참여했습니다. 이를 바탕으로 클라이언트와 서버 사이의 데이터 흐름과 처리 과정을 이해하며 기능을 개발할 수 있습니다.

AI를 단순한 코드 생성 도구가 아닌 개발 생산성을 높이기 위한 도구로 적극 활용하고 있습니다. 설계, 구현, 검증 단계에 AI 에이전트를 적용하여 탐색과 반복 작업에 드는 시간을 줄이고, 결과를 검토하고 검증하며 개발 효율을 높이고 있습니다.
