Unreal Engine 4·5와 C++로 VR·모바일 게임 클라이언트를 개발해 온 5년차 프로그래머로, 총 3개의 프로젝트에서 기획 단계부터 출시 후 라이브 서비스까지의 전체 개발 주기를 경험하고 5개 플랫폼(Meta Quest, Pico, Steam, Android, iOS)에 대응했습니다.

문제가 발생하면 눈에 보이는 현상만 임시로 수정하기보다 로그와 코드를 따라가며 원인을 찾습니다. VR 환경에서는 핸드 트래킹, Passthrough, 궤적 기반 전투 판정 등 플랫폼 특화 기능을 다뤘고, 모바일 환경에서는 캐릭터 외형과 스킬·버프를 데이터 드리븐 구조로 설계했습니다. Protobuf 기반 서버 연동과 C++ 서버 콘텐츠까지 함께 다루며 클라이언트와 서버를 아우르는 개발을 수행했습니다.

평소 신속한 프로토타이핑으로 핵심 재미를 검증하고, 기능을 구현할 때는 이후의 수정과 확장까지 고려합니다. 최근에는 AI를 코드 생성에만 사용하지 않고, 스펙 기반 작업 분해와 구현, 예외 케이스 점검, E2E·evaluator 검증에 활용해 개발 생산성과 결과물의 품질을 함께 높이고 있습니다.

접근

클라이언트–서버 연동 및 서버 콘텐츠

담당
Protobuf 기반 패킷 정의와 처리 흐름을 클라이언트–서버 양쪽에서 구현해 콘텐츠를 연동했습니다. 서버 ObjId 기반 네트워크 오브젝트 생성과 상태 동기화, 서버 응답 기반 액션 실행과 클라이언트 연출도 함께 연결했습니다. 서버 대미지 계산 파이프라인은 계산 단계를 정리해 스킬·버프 효과가 일관되게 반영되도록 정비했고, 인벤토리 갱신은 전체 데이터를 내려보내는 대신 Storage Delta로 변경분만 전달하도록 구조를 바꿔 동기화 비용을 줄였습니다.
의미
클라이언트 경계에서 멈추지 않고 서버 로직까지 함께 수정하며 문제를 끝까지 처리했습니다.
